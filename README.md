One word an agent says when it has no idea what to do: **recalculating** — the word a GPS blurts out mid-journey when it has lost the route. It is a genuine one-word reaction to being completely lost, it lands instantly, and it sounds exactly like a machine caught out mid-task.

`main.ts` (Node 22, standard library only) validates the word against the gate — one word, 1–99 characters, not only whitespace — and writes it exactly to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
